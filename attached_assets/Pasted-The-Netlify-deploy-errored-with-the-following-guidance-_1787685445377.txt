The Netlify deploy errored, with the following guidance provided:

The build is failing due to Netlify's secrets scanning detecting the value of the `NEXT_PUBLIC_SUPABASE_URL` environment variable in the build output (see [lines 264–266](#L264-L266)).

The root cause is that `NEXT_PUBLIC_*` variables in Next.js are **inlined into the client-side bundle at build time**, which means their values appear in plain text in the compiled output. Netlify's secrets scanner flags this as a potential secret exposure.

**Solution**

Since `NEXT_PUBLIC_SUPABASE_URL` is intentionally a public-facing value (it's a Supabase project URL meant to be exposed to the browser), you can tell Netlify's secrets scanner to ignore this key. Add the following environment variable to your Netlify site settings or `netlify.toml`:

```toml
[build.environment]
  SECRETS_SCAN_OMIT_KEYS = "NEXT_PUBLIC_SUPABASE_URL"
```

If you also want to omit multiple keys, separate them with commas:

```toml
[build.environment]
  SECRETS_SCAN_OMIT_KEYS = "NEXT_PUBLIC_SUPABASE_URL,NEXT_PUBLIC_SUPABASE_ANON_KEY"
```

Alternatively, you can configure this via the Netlify UI under **Site configuration → Environment variables**, or disable secrets scanning entirely with `SECRETS_SCAN_ENABLED = "false"` (not recommended unless necessary).

For more details, refer to the [Netlify secrets scanning documentation](https://ntl.fyi/configure-secrets-scanning).
